# Builder names the migration ledgers are licensed to mention.
#
# docs/builder-contract-release-1.md is the record of what the
# builder-contract epic deleted, so it names hundreds of functions that
# pkg/ no longer exports -- in its tables, in its prose, and in the
# "before" half of its code blocks. Those references are the page doing
# its job, not rot, and check-doc-api-refs.sh exempts them by name.
#
# The exemption cannot be derived from the page. Its tables are not all
# removal tables: some pair an old signature with a new one under the
# same name, some pair a builder that still ships with the field it no
# longer sets, and some list helpers that stay and say why. A rule that
# read "the non-final cells are the removed names" would exempt around
# thirty live builders the page recommends -- including the ones it
# recommends most.
#
# So the list is written down instead, and the check validates it: every
# name here must be absent from pkg/, and a name the ledger mentions
# that is neither exported nor listed fails the build. That makes an
# omission loud, and it makes the list a snapshot -- deleting a builder
# tomorrow does not quietly add it to what the ledger may mention.
#
# To regenerate after a ledger change, run the check and add the names it
# reports, once you have confirmed each one really is gone rather than
# misspelled.
#
